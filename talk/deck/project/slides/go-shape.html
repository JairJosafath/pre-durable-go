On a drafting grid the signature of durable.Step types itself, then six parts light up in turn, each with a bracket and a dashed leader to its label, alternating above and below: generic over the result; the context comes first; a name, for the history; your code, where StepContext has no operations; options are functions; your type, plus an error. About ten seconds. In TypeScript you write context.step(...); in Go you write durable.Step(ctx, ...). The operations are package-level generic functions that take the context first, which is how the result comes back as your own type O alongside an error. The handler is generic too: you pick the event and output types and the SDK decodes and encodes them with encoding/json. durable.Start registers with the Lambda runtime; durable.Wrap returns a raw payload function if you compose your own entry point. A step body receives a StepContext, which is a context.Context with a logger and an attempt counter but no durable operations; capturing the outer context instead is rejected at run time with ErrWrongContext.
