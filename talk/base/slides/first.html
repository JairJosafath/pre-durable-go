How it works

A first durable function

1:30 to 2:30. No clicks. Style: live code. The function types itself in about five seconds, then three callouts draw out from the lines they describe, a second or so apart. This is the getting-started function from the repo, trimmed. Talk while it types: a durable handler is an ordinary Go function with a durable.Context. Callout 1, Step: durable.Step takes the context, a name, and a function; its return value is what gets checkpointed. Callout 2, Wait: durable.Wait suspends for ten seconds, and the invocation actually ends here. Callout 3, Logger: the handler body runs from the top a second time after the wait, but the logger suppresses records it already emitted. main is just durable.Start(handler).
