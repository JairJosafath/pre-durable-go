The SDK · Operations

Eight operations

Step

Step

Run code, checkpoint the result, retry on failure.

Wait

Wait

Pause for a duration without using compute.

Wait for Condition

WaitForCondition

Poll a check on a schedule until it passes.

Callback

WaitForCallback

Suspend until an external system answers.

Invoke

Invoke

Call another function and wait for its result.

Parallel

Parallel

Run a fixed set of named branches concurrently.

Map

Map

Apply one function to every item, concurrently.

Child Context

RunInChildContext

Group operations into an isolated subflow.

Every operation takes the context first and a name second. The name identifies it in the execution history.

4:30 to 5:30. The same eight operations exist in every SDK: TypeScript, Python, Java, Go, C#, and Rust in preview. The teal line on each card is the Go function in package durable. Group them when you talk: Step is the unit of work. Wait, Wait for Condition and Callback are three ways to suspend. Invoke composes functions. Parallel, Map and Child Context structure concurrency: Map is one function over many items, Parallel is different branches at once, and both run each item in its own child context. Go adds async variants (StepAsync, WaitAsync, InvokeAsync) plus Go, Retry and combinators, which come up in part two. Names do not have to be unique, but descriptive names make logs and tests readable.
